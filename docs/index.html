About the projectО проекте

These remakes don’t rewrite the games. Each one runs the original ZX Spectrum program, unmodified, in an emulator at its own speed. Every frame the remake reads the game’s state from the Spectrum’s memory (the level, the bricks, the ball, the creatures) and draws new art in the same places. So the rules, the timing and the quirks are the original’s; only the look and the sound are new.

Эти ремейки не переписывают игры. Каждый запускает оригинальную программу для ZX Spectrum без изменений, в эмуляторе и с её родной скоростью. Каждый кадр ремейк читает состояние игры из памяти Спектрума (уровень, кирпичи, мяч, существ) и рисует на тех же местах новую графику. Правила, темп и все особенности остаются оригинальными, новые только картинка и звук.

Press Tab while playing to see the 1987 original at any moment.

Нажмите Tab во время игры, чтобы в любой момент увидеть оригинал 1987 года.
